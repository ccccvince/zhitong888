> 基于 **FastAPI + WebSocket + SQLite(WAL) + 原生极简 Canvas 金融前端** 构建的轻量级、企业级 A 股智能盯盘、T+1 模拟撮合交易与量化投研副驾驶平台。
> 支持多用户完全数据隔离、邮件验证码注册、通用 OpenAI 兼容大模型（DeepSeek / 通义千问 / Ollama 等）、5日涨停连板雷达及全套自动化策略与回测。

---

## 🌟 核心特性全览

### 1. 真实盘口与 24h 仿真推演双模引擎
- **真实盘口（盘中每 3 秒实时轮询）**：聚合腾讯行情源与 `adata` 财经接口，获取沪深北全市场股票的最新价、涨跌幅、成交额、换手率、振幅及**真实五档委买委卖盘口**与**委比实时指示条**。
- **24h 仿真推演模式**：在休市或非交易时段，可一键切换为推演模式，支持全天候单步推进盘口和价格波动，随时测试策略逻辑、下单撮合及风控告警。

### 2. 严谨的 A 股交易撮合与风控熔断机制 (`PaperBroker`)
- **T+1 制度与持仓解锁**：买入股数当日冻结（`today_bought_qty`），次日收盘清算后自动解锁为可用持仓；买入必须为 100 股整数倍。
- **五档深度撮合**：按真实五档对手盘深度逐档撮合，支持部分成交、限价更优成交差额退款，严格规避涨跌停一字板无法成交的极端行情。
- **真实规费计算**：自动计提佣金（万 2.5，最低 5 元）、过户费（万 0.1）、卖出印花税（万 5）。
- **账户级多维风控**：支持单票最大持仓占比限制、单笔最大买入金额限制、全账户总亏损熔断拦截（触发后禁止新买入，仅允许卖出平仓）。

### 3. 全市场近 N 日涨停选股雷达 (`Limit-Up Radar`)
- 自动抓取并聚合全市场近 3~10 个交易日涨停池数据，支持按主板、创业板、科创板、北交所筛选。
- 展示涨停天数、连板高度（首板/多连板）、所属行业题材、换手率与成交额；支持一键加自选与 AI 主线归纳。

### 4. 策略工坊与量化回测系统
- **自动盯盘策略**：支持网格低吸高抛、价格/放量突破追涨、持仓动态止盈止损、MA 双均线金叉死叉、MACD 趋势金叉死叉自动化策略。
- **历史日线回测**：支持 30~250 天历史 K 线策略回测，扣除真实佣金与印花税，精确绘制策略收益 vs 基准指数对比曲线，输出总收益率、超额收益、最大回撤、胜率与交易明细清单。

### 5. 通用 OpenAI 兼容 AI 投研副驾驶 (`AIAssistant`)
- **零门槛接入各类大模型**：兼容 OpenAI API 规范，支持 DeepSeek、阿里云通义千问、月之暗面、以及本地 Ollama / vLLM / LM Studio 端口。
- **全屏高度投研抽屉**：支持个股盘面诊断、涨停板题材复盘、账户体检复盘；AI 回复可附带**结构化参数草稿卡片（Action Drafts）**，用户点击即可一键填入下单、加预警或建回测。
- **公网 SSRF 严格防护**：生产部署模式下自动拦截针对本机回环（127.0.0.1）和云服务器元数据地址（169.254.169.254）的请求。

### 6. 多租户数据隔离与多通道邮件系统
- **用户空间完全隔离**：每位用户独立拥有资金账户、持仓流水、自选池、风控规则、策略与个人专属 API Key。
- **灵活的邮件与注册体系**：
  - 支持 **Brevo（原 Sendinblue，每日 300 封免费）**、**Resend** 或**传统 SMTP 服务**。
  - 支持邮箱验证码注册、邮箱密码找回重置、以及价格预警触发同步邮件提醒。
  - 管理员可随时一键切换为邀请码内测制或开放注册制。

## 🚀 快速启动

### 方式一：本地 Python 环境运行

#### 1. 准备环境
要求 Python 3.10 或更高版本（推荐 Python 3.12）：
```bash
git clone https://github.com/ccccvince/zhitong888.git
cd zhitong888

# 创建并激活虚拟环境
python3 -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows:
.\.venv\Scripts\Activate.ps1

# 安装依赖
pip install -r requirements.txt
```

#### 2. 配置环境变量
复制配置模板：
```bash
cp deploy/.env.example .env
```
根据需求修改 `.env`（本地测试可使用默认配置）。

#### 3. 启动服务
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8765 --workers 1
```
打开浏览器访问：`http://127.0.0.1:8765`

### 方式二：Docker & Docker Compose 一键部署

项目已内置完整的容器化配置：
```bash

docker compose up -d

docker compose logs -f
```

## ⚙️ 核心环境变量说明 (`.env`)

| 变量名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `TZ` | `Asia/Shanghai` | 强制锁定系统时区为北京时间（避免服务器默认 UTC 造成开收盘计算错误） |
| `PAPER_TRADE_DB` | `data/paper_trade.db` | SQLite 数据库文件持久化路径 |
| `AUTH_REQUIRED` | `true` | 是否启用多用户登录鉴权（设为 `false` 则为单机免登录模式） |
| `INVITE_REQUIRED` | `false` | 是否开启邀请码注册（`false` 时任何人均可注册，`true` 时必须填邀请码） |
| `EMAIL_VERIFICATION_REQUIRED`| `false` | 注册时是否强制要求输入邮箱验证码（测试阶段可先设为 `false`） |
| `SITE_URL` | `https://your-domain.com` | 当前站点访问根地址（用于邮件验证码中的链接展示） |
| `BREVO_API_KEY` | *(可选)* | Brevo 发信密钥（以 `xkeysib-...` 开头，每天免费 300 封，推荐） |
| `RESEND_API_KEY`| *(可选)* | Resend 发信密钥（以 `re_...` 开头） |
| `EMAIL_FROM` | `智瞳量化 <noreply@domain>` | 发信人显示地址（在邮件服务商完成域名验证后填写） |
| `APP_SECRET_KEY`| *(必填随机字符串)* | 用于 Session 签名的防伪密钥 |
| `ADMIN_USERNAME`| `admin` | 首次启动自动创建的管理员账号用户名 |
| `ADMIN_PASSWORD`| *(必填强密码)* | 首次启动自动创建的管理员初始密码 |
| `PUBLIC_AI_API_KEY`| *(可选)* | 平台公用 AI Key（配置后可免费向注册用户赠送每日限制次数的 AI 体验） |

## 🛡️ 安全合规与注意事项

1. **单进程运行约定 (`--workers 1`)**：由于盘中盯盘协程、内存行情缓存及 WebSocket 会话连接池运行于进程内存中，请始终保持 `--workers 1` 启动；生产环境多并发场景应前置 Nginx / Cloudflare 负责静态资源缓存与 TLS 卸载。
2. **合规提示**：本软件仅用于 A 股模拟量化研究、行情数据分析与编程学习，**不接入任何实盘券商交易接口**，不构成任何实质性投资建议。
